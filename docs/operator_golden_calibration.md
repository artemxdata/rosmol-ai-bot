# Калибровка по ответам операторов

## Назначение

Набор построен из обезличенных пар «обращение — ответ оператора» за июнь 2026 года. Ответы операторов используются как материал для анализа поведения и ручного ревью, но не индексируются автоматически в RAG и не считаются безусловно достоверной базой знаний.

Набор разделён на две части:

- `Calibration 200` — разрешён для анализа ошибок и настройки ядра;
- `Holdout 100` — закрытая независимая проверка после завершения калибровки.

Из выборки исключены персональные и ручные статусы, подписи операторов, номера тикетов, запросы с чувствительными данными, контекстные обрывки и служебные сообщения подключения оператора.

## Результат calibration live

Проверены все 200 калибровочных кейсов локально через `/ask`, без HDE и без семантического кеша:

- HTTP-успешность: 100%;
- покрытие trace: 100%;
- самостоятельный ответ без оператора: 137 из 200, или 68,5%;
- безопасное уточнение: 55;
- controlled escalation: 8;
- ответы с cited source IDs: 137 из 137 автоответов;
- медиана: 1,27 с;
- p95: 51,63 с;
- максимальная задержка: 77,59 с;
- оценочная стоимость LLM: 12,60 руб.

Уточнение не считается закрытым обращением. Метрика конверсии отражает только первый содержательный ответ без участия оператора.

## Сильные и слабые зоны

Конверсия по крупным категориям:

| Категория | Кейсов | Без оператора |
| --- | ---: | ---: |
| Гранты | 36 | 88,9% |
| Форумы | 117 | 70,1% |
| ФГАИС | 15 | 53,3% |
| Техподдержка | 18 | 50,0% |
| Навигация | 14 | 42,9% |

Основные зоны роста: документы, проживание и питание, проезд и трансфер, технические ошибки, профиль ФГАИС и вопросы без явно названного мероприятия. Большая часть незакрытых кейсов требует уточнения события, потому что правила различаются между форумами. Такие уточнения безопаснее, чем ответ по случайному похожему источнику.

## Ограничения интерпретации

- Holdout 100 не запускался и не использовался для настройки.
- Лексическое сходство с формулировкой оператора применяется только для формирования очереди ручного ревью и не является оценкой фактической правильности.
- Корректность фактов подтверждается источниками RAG и должна дополнительно проверяться выборочным ручным ревью.
- Высокий p95 требует отдельной оптимизации медленных retrieval/LLM-сценариев.

## Следующий quality gate

1. Вручную проверить репрезентативную выборку автоответов из каждой категории.
2. Расширить подтверждённые инструкции по слабым темам в Yonote/RAG.
3. Повторить только calibration-набор и сравнить конверсию, grounded rate и p95.
4. После фиксации ядра один раз открыть Holdout 100 и принять решение о готовности к пилоту.
